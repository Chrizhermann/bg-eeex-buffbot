BuffBot automates pre-battle buffing in BG2:EE and EET. It scans each party member's spellbook, builds a configurable buff list, and casts everything in parallel with one click. Think Bubble Buffs from Pathfinder: WotR, adapted for the Infinity Engine.

This is an alpha release — fully functional but with rough edges. I'm looking for testers and feedback.

Video showcase: https://www.youtube.com/watch?v=9fjnUKG1tfQ

What It Does

  • Scans spellbooks dynamically — no hardcoded spell lists. Memorized spells, innates, HLAs, kit abilities — if a character has it and it's a buff, BuffBot finds it
  • In-game config panel (F11) — per-character tabs, up to 8 presets, spell list with enable/disable, duration display, target assignment, and priority ordering
  • Smart targeting — ordered priority list with fallback chain. Assign specific characters as targets with preferred order, or party-wide / self. Name-based storage survives party rearrangement
  • Quick Cast mode — toggle per-preset for instant casting via Improved Alacrity. "Long only" mode fast-casts long buffs, then casts short buffs normally
  • Subwindow selection spells — spells like Protection from Elemental Energy that open a selection popup are handled seamlessly. Pre-configure which variant to cast, BuffBot bypasses the popup entirely
  • F12 innate abilities — one per preset per character, trigger buffing directly from the special abilities menu
  • Skip active buffs — detects what's already running and skips it. Two-tier detection: SPLSTATE fast path with effect list fallback
  • Combat safety — detects nearby enemies and interrupts casting to avoid wasting buffs mid-fight
  • Manual override — classifier got it wrong? "Add Spell" to include, "Remove" to exclude
  • Export/Import — save a character's config to a file, load it onto another character or share it
  • Mod-friendly — tested with SCS and Spell Revisions. Reads spell data at runtime, so mod-added spells appear automatically
  • 200+ automated tests — built-in test suite runnable in the EEex console

Requirements

  • BG2:EE or EET
  • EEex v0.11.0-alpha or later

Download & Install

  1. Download from GitHub Releases
  2. Extract into your game directory
  3. Run setup-buffbot.exe → select "BuffBot: In-Game Buff Automation"

Standard WeiDU install. Uninstall by re-running setup.

Quick Start

  1. Press F11 to open the panel (or click the actionbar button)
  2. Select a character tab
  3. Select a preset ("Long Buffs" or "Short Buffs")
  4. Enable/disable spells, set targets, reorder with Up/Down
  5. Click Cast

That's it. BuffBot casts everything in order across all party members simultaneously.

Known Limitations

Alpha means alpha:

  • Spell Revisions edge cases — SR restructures some spells (Barkskin, Dispelling Screen) via sub-spells. The classifier may mark them as ambiguous. Use "Add Spell" to include them manually
  • Windows only for file picker — export/import file listing uses dir /b. Core file I/O is cross-platform, but the import picker won't enumerate files on macOS/Linux
  • No item/potion/scroll support yet — currently spells and innates only. Item buff sources are planned
